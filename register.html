선수 등록

본인 계정임을 확인한 뒤 랭킹에 추가됩니다. 2분이면 끝납니다.

1단계 · 내 인증 아이콘 번호 확인

Riot ID를 입력하면 본인 인증에 사용할 프로필 아이콘 번호가 나옵니다.

형식이 올바르지 않습니다. 이름#태그 형태로 입력해 주세요. (예: 홍길동#KR1)

번 아이콘
게임 클라이언트에서 이 아이콘으로 바꾼 뒤 2단계로 넘어가세요.
아이콘 번호는 Riot ID마다 고정입니다. 인증이 끝나면 원하는 아이콘으로 되돌려도 됩니다.

2단계 · 게임에서 아이콘 변경

  1. 롤 클라이언트 실행 → 우측 상단 내 프로필 클릭
  2. 프로필 아이콘 클릭 → 위에서 안내된 번호의 기본 아이콘 선택
  3. 로비 화면으로 나오기 (변경 사항이 서버에 반영됩니다)

아이콘 변경이 조회에 반영되기까지 몇 분 걸릴 수 있습니다.

3단계 · 등록 신청

아래 항목을 신청서에 적어 보내주세요. 운영자가 아이콘을 확인한 뒤 승인합니다.

  • Riot ID (예: 홍길동#KR1)
  • 표시할 이름 (실명 또는 활동명)
  • 소속 (학교 / 팀 / 클럽)
  • 지역 (천안, 아산, 공주 …)
  • 주 포지션

신청서 작성하기

승인 기준: 충남 소재 학교·팀 소속이거나 충남 거주 아마추어 선수여야 합니다. 프로게이머 및 프로팀 소속 연습생은 등록할 수 없습니다.

개인정보 안내

  • 공개되는 정보: 표시 이름, Riot ID, 소속, 지역, 포지션, 티어·전적
  • 수집 목적: 지역 아마추어 랭킹 집계 및 공개
  • 보관 기간: 삭제를 요청할 때까지
  • 만 14세 미만은 보호자 동의가 필요합니다.
  • 삭제를 원하면 로 Riot ID를 알려주세요. 랭킹·기록에서 즉시 지웁니다.
