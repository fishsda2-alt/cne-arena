스타크래프트 선수 등록

래더 화면 스크린샷 한 장이면 됩니다. 스크린샷은 사이트 밖으로 나가지 않습니다.

스타크래프트: 리마스터는 블리자드가 래더 정보를 외부에 열어 두지 않아서, 롤처럼 자동으로 가져올 수 없습니다. 그래서 선수 본인이 확인한 값으로 올리고, 랭킹표에는 본인 등록 / 날짜 가 함께 표시됩니다. 실력이 바뀌면 같은 게임 아이디로 다시 등록하면 그날 값으로 바뀝니다.

1 래더 화면 캡처

  1. 스타크래프트: 리마스터 실행 → 래더 화면(또는 내 프로필의 래더 기록)
  2. 등급 · 레이팅 · 승/패가 한 화면에 보이는 상태에서 캡처
  3. Win + Shift + S 로 잘라 복사하면 아래에 바로 붙여넣기(Ctrl+V) 할 수 있습니다. 파일로 저장해서 골라도 됩니다.

게임 창을 크게 띄운 채 찍을수록 잘 읽힙니다. 흐리거나 너무 작으면 숫자를 못 읽습니다.

2 스크린샷 올리기

래더 화면 스크린샷을 먼저 올려 주세요.

글자를 읽는 중…

글자 읽기는 이 컴퓨터의 브라우저 안에서만 이뤄집니다. 스크린샷 파일은 어디에도 올라가지 않고, 아래에서 확인한 숫자만 전송됩니다. (처음 한 번은 글자 인식 데이터를 받느라 10~20초 걸릴 수 있습니다)

3 읽은 값 확인하기

왼쪽 스크린샷과 오른쪽 값을 한 칸씩 대조해 주세요. 글자 인식은 자주 틀립니다. 다르면 직접 고치면 됩니다.

등급을 골라 주세요.

레이팅을 숫자로 입력해 주세요. (배치 전이면 등급을 '배치 전'으로)

승·패는 숫자만 입력해 주세요.

래더 순위는 1 이상의 숫자로 입력해 주세요.
